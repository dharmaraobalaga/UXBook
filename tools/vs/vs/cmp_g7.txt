Q91. UI Design vs UX Design
UX Design (User Experience Design)

ఒక ప్రొ డక్ట్‌ను ఉపయోగించేటప్పుడు యూజర్‌కు కలిగే మొత్తం అనుభవాన్ని డిజైన్ చేయడం.

English: UX Design focuses on the overall user experience, including usability, accessibility, user flows, and problem-solving.

UI Design (User Interface Design)

యూజర్ ప్రొ డక్ట్‌తో ఇంటరాక్ట్ అయ్యే స్క్రీన్లు , బటన్లు , కలర్స్, టైపోగ్రఫీ, విజువల్ ఎలిమెంట్స్‌ను డిజైన్ చేయడం.

English: UI Design focuses on the visual and interactive elements of a digital product.

UX Design                                                       UI Design

User experience                                                 Visual interface

Research & usability                                            Colors & typography

User journeys & flows                                           Buttons & components

Information architecture                                        Visual consistency

How it works and feels                                          How it looks and responds




UX: Structure & flow                                                                          UI: Visual interface

Practical Example – Banking App

UX Designer: యూజర్ డబ్బులు ఎలా ట్రా న్స్‌ఫర్ చేయాలి? ఎన్ని స్టెప్స్ ఉండాలి? ఎక్కడ కన్ఫ్యూజన్ వస్తుంది?

UI Designer: Transfer button ఎలా ఉండాలి? Color, typography, spacing, icons ఎలా ఉండాలి?

Interview Answer:

"UX Design focuses on creating meaningful, usable, and accessible experiences, while UI Design focuses on the visual and interactive presentation of
those experiences. Both disciplines work together to create successful digital products."




Q92. Design System vs Style Guide
Design System
ఒక ప్రొ డక్ట్ లేదా సంస్థలో consistent digital experiences తయారు చేయడానికి ఉపయోగించే components, patterns, tokens, guidelines, documentation, governance
కలిగిన వ్యవస్థ .

English: A Design System is a structured collection of reusable components, design foundations, patterns, and guidelines.

Style Guide

ఒక బ్రాండ్ లేదా ప్రొ డక్ట్ యొక్క visual appearance ఎలా ఉండాలో చెప్పే నియమాలు.

English: A Style Guide defines visual standards such as colors, typography, logos, and spacing.

Design System                                                            Style Guide

Broader system                                                           Visual rules

Components & patterns                                                    Colors & fonts

Design tokens                                                            Brand guidelines

Documentation & governance                                               Visual consistency

Design–development alignment                                             Appearance alignment

Practical Example

D’SARAS వెబ్‌సైట్ కోసం colors, typography, logo usage మాత్రమే document చేస్తే అది Style Guide.

అదే reusable buttons, navigation, forms, tokens, responsive patterns, usage rules, code alignment కలిపితే Design System.

Interview Answer:

"A Style Guide defines the visual language of a product, whereas a Design System provides a comprehensive framework of reusable components,
patterns, tokens, and guidelines to ensure consistency and scalability."




Q93. Design System vs Component Library
Design System: Components‌తో పాటు principles, patterns, tokens, accessibility standards, documentation, governance కలిగి ఉంటుంది.

Component Library: Reusable UI components యొక్క collection.

Design System                                                    Component Library

Complete framework                                               Reusable UI elements

Includes design principles                                       Buttons, cards, inputs

Guidelines & governance                                          Component states

Supports scalability                                             Supports implementation


Example: Material Design ఒక Design System. దాని Material UI component implementations అనేవి component libraries.

Interview Answer:

"A Component Library is one part of a Design System. A Design System additionally defines design principles, usage guidelines, accessibility standards,
and governance."




Q94. Component vs Pattern
Component

ఒక నిర్దిష్ట UI functionality అందించే reusable building block.
Examples: Button, Checkbox, Text Field, Modal.

Pattern

ఒక common user problem‌ను పరిష్కరించడానికి ఉపయోగించే repeatable design solution. ఇందులో అనేక components ఉండవచ్చు.

Examples: Login Flow, Search & Filter, Checkout, Multi-step Form.

Component                                                      Pattern

UI building block                                              Reusable solution

Usually smaller scope                                          Often broader scope

Button, input, card                                            Checkout, authentication

Implementation-focused                                         Interaction-focused


Practical Example – E-commerce

Search Input = Component.

Search + Suggestions + Filters + Results + Empty State = Search Pattern.

Interview Answer:

"A Component is a reusable interface element, while a Pattern is a repeatable solution to a common user interaction problem, often combining multiple
components."

Component

ఒక reusable UI element యొక్క base definition.

Variant

అదే component‌కు చెందిన different versions లేదా properties ఆధారంగా మారే రూపాలు.

  Button component – common variants

    Primary           Secondary      Disabled

  Illustrative button variants; a real component also defines states and interaction behavior.


Component                                                      Variant

Base reusable element                                          Version of that element

Button                                                         Primary, Secondary

Input Field                                                    Default, Error, Success

Card                                                           Compact, Expanded


Figma Example: Button Component Set → Properties: Type, Size, State.

Interview Answer:

"A Component defines a reusable UI element, while Variants represent different configurations of that component, helping designers manage consistency
and reduce duplication."




Q96. Design Tokens vs Design Variables
Design Tokens

Design decisions‌ను meaningful names‌తో represent చేసే reusable values.

Examples:

       color.primary = #2563EB
       spacing.md = 16px
       radius.card = 12px

Design Variables

Figma వంటి tools‌లో values‌ను store చేసి, reuse చేసి, modes ద్వారా manage చేయడానికి ఉపయోగించే features.

Design Tokens                                                  Design Variables

Named design decisions                                         Tool-managed values

Tool-independent concept                                       Tool-specific implementation

Can be exported to code                                        Can support modes

Supports cross-platform systems                                Supports design workflows


Practical Example

color.background.primary అనే token‌ను Figma Variable‌తో link చేయవచ్చు . Light Mode, Dark Mode‌లో వేర్వేరు values ఇవ్వవచ్చు .

Interview Answer:

"Design Tokens represent named design decisions, while Design Variables are mechanisms used by design tools to store, reference, and manage
values. Variables can implement tokens, but the two concepts are not identical."




Q97. Atomic Design vs Design System
Atomic Design

UI‌ను చిన్న building blocks నుంచి పెద్ద structures వరకు organize చేసే methodology.

Brad Frost పరిచయం చేసిన Atomic Design methodologyలో ఐదు levels ఉన్నాయి.


                                                               Atoms — Buttons, Labels, Inputs




                                                                  Molecules — Search Form




                                                                Organisms — Website Header




                                                                 Templates — Page Structure




                                                               Pages — Real Content & States


Design System

Reusable UI, design principles, standards, documentation, governance అన్నింటినీ నిర్వహించే framework.

Interview Answer:

"Atomic Design is a methodology for structuring interfaces into hierarchical building blocks. A Design System is a broader framework for creating,
maintaining, and governing consistent product experiences."

Typography

Font
ఒక typeface యొక్క specific style, weight, size లేదా implementation.

Typography                                                    Font

Hierarchy                                                     Typeface, weight, style

Line height & spacing                                         Font selection

Readability & legibility                                      Character appearance

Roboto Bold 24px ఒక font specification.

Padding

ఒక element యొక్క content మరియు దాని boundary మధ్య ఉండే internal spacing.

Margin

ఒక element boundary బయట, ఇతర elements‌తో దూరం కల్పించే external spacing.




                             Margin

                                           Padding

Practical Example

Button లో text చుట్టూ      16px internal spacing = Padding.

రెండు buttons మధ్య 12px gap కోసం ఒక button‌కు external margin ఇవ్వవచ్చు. Modern layouts‌లో parent gap property కూడా ఉపయోగిస్తా రు.

Q100. Grid System vs Layout System
Grid System

Columns, gutters, margins ఉపయోగించి elements‌ను align చేసే structure.

Layout System

Grid‌తో పాటు spacing, positioning, containers, responsive behavior, Flexbox వంటి rules‌ను కలిగి ఉండే broader arrangement framework.

Grid System                                                  Layout System

Alignment framework                                          Overall arrangement rules

Columns & gutters                                            Grid, flex, spacing

Structural consistency                                       Responsive composition

Often a layout technique                                     Broader layout approach


Example

12-column desktop grid = Grid System.

Sidebar + Header + Main Content + responsive behavior = Layout System.

Interview Answer:

"A Grid System provides a structured alignment framework, while a Layout System defines how all interface elements are arranged and adapt across
screen sizes."




Q101. Responsive Grid vs Fixed Grid
Responsive Grid

Screen size లేదా container width ఆధారంగా columns, spacing, dimensions మారే grid.

Fixed Grid

నిర్దిష్ట width లేదా column dimensions‌తో పనిచేసే grid.

  Responsive grid illustration




  Desktop: 4 columns                                                                     Mobile: 1 column


Interview Answer:

"A Responsive Grid adapts its structure to different screen sizes or containers, whereas a Fixed Grid maintains predefined dimensions. Responsive grids
are generally more suitable for multi-device digital products."




Q102. Visual Hierarchy vs Information Hierarchy
Visual Hierarchy

Size, color, contrast, position, spacing ద్వారా యూజర్ attention‌ను guide చేయడం.

Information Hierarchy

Content‌ను importance, relationships, logical structure ఆధారంగా organize చేయడం.

Visual Hierarchy                                          Information Hierarchy
Visual priority                                     Content priority

Size, color, contrast                               Meaning, grouping, order

Guides attention                                    Guides understanding

Presentation-focused                                Content-structure-focused


Practical Example – Product Detail Page

Information Hierarchy: Product Name → Price → Description → Reviews.

Visual Hierarchy: Large Product Name → Bold Price → Prominent Buy Button.

Interview Answer:

"Information Hierarchy organizes content based on meaning and importance, while Visual Hierarchy uses visual design techniques to communicate that
importance and guide user attention."




Q103. Contrast vs Accessibility
Contrast

రెండు visual elements మధ్య ఉన్న difference. ఉదాహరణకు text మరియు background మధ్య brightness difference.

Accessibility

వివిధ abilities ఉన్న వ్యక్తు లు కూడా digital products‌ను perceive, understand, navigate, operate చేయగలిగేలా డిజైన్ చేయడం.

Contrast                                                 Accessibility

Visual property                                          Broader inclusive requirement

Helps distinguish elements                               Supports diverse abilities

Text/background readability                              Keyboard, screen reader, touch

One accessibility consideration                          Multiple accessibility dimensions


WCAG 2.2 ముఖ్యమైన contrast guidelines:

     Normal text: కనీసం 4.5:1
     Large text: కనీసం 3:1
     Essential UI components మరియు graphical objects: సాధారణంగా 3:1

ఈ ratios WCAG AAలో సంబంధిత success criteriaకి వర్తిస్తా యి; అన్ని visual elements‌కు ఒకే నియమం కాదు.

Interview Answer:

"Contrast is one important aspect of visual accessibility, but accessibility is broader. It also includes keyboard navigation, screen-reader support,
meaningful labels, focus management, and inclusive interaction patterns."




Q104. Brand Identity vs Visual Identity
Brand Identity

ఒక బ్రాండ్ ఏమిటి, దాని values, personality, positioning, purpose, communication ఎలా ఉండాలి అనే broader identity.

Visual Identity

ఆ బ్రాండ్‌ను visually represent చేసే logo, colors, typography, imagery, graphic elements.

Brand Identity                                                Visual Identity

Brand personality                                             Visual representation

Mission & values                                              Logo & colors

Positioning & voice                                           Typography & imagery

Broader brand expression                                      Visual expression
Practical Example – D’SARAS

Brand Identity: Design, Knowledge, Intelligence అనే positioning, purpose, personality.

Visual Identity: D’SARAS Logo, VIBGYOR-inspired palette, typography, graphic style.

Interview Answer:

"Brand Identity represents the overall personality, values, and positioning of a brand, while Visual Identity expresses that brand through visual elements
such as logos, colors, typography, and imagery."
